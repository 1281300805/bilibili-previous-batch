# B站推荐上一批

一个面向 Chrome 的本地扩展，为 B 站首页的“换一换”增加：

- “上一批”按钮；
- 最近 10 批推荐的页面内历史；
- 650 毫秒防连点，避免一次误触刷新两批。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目文件夹。
5. 打开或刷新 B 站首页。

## 使用

正常点击“换一换”后，下面的“上一批”按钮会亮起，右上角数字表示还可以返回多少批。

历史只保存在当前 B 站标签页的内存中，刷新或关闭标签页后会清空。扩展不读取账号信息、不上传数据，也不向外部服务器发送请求。

返回的批次使用推荐卡片的页面快照显示。视频封面、标题和作者链接可以正常点击；B 站依赖内部脚本的少量悬停动画可能不会完全恢复。
