# 小黑盒发布稿

## 推荐标题

B站“换一换”点快了找不回？我做了个“上一批”Chrome插件

## 正文

不知道有没有盒友遇到过这种情况：

刷 B 站首页时连续点了两下“换一换”，中间那批推荐一闪而过，偏偏里面有个标题或者封面挺想看的。再继续刷新，基本就很难找回来了。

这是一个很小但一直让我不舒服的交互，所以我做了一个 Chrome 扩展：**B站推荐上一批**。

### 它做了什么

扩展会在原来的“换一换”按钮下面增加一个“上一批”：

- 每次正常刷新前，保存当前推荐；
- 可以连续返回最近 10 批；
- 给“换一换”增加 650 毫秒防连点；
- 返回后，视频封面、标题和作者链接仍然可以点击。

### 为什么不是直接修改 B 站推荐数据

第一版采用的是页面快照方案。扩展保存当前推荐卡片，返回时将快照临时显示在原推荐区上方。B 站自己的实时推荐区仍然留在页面中，不会修改账号偏好或服务器端推荐数据。

这样实现比较轻量，也不需要读取 Cookie 或调用私人接口。代价是返回批次中的少量悬停动画可能无法完全恢复。

### 隐私

扩展没有后台服务：

- 不读取 Cookie；
- 不访问浏览历史；
- 不上传推荐内容；
- 不向外部服务器发送请求；
- 历史只存在当前标签页内存中，刷新页面后自动清空。

### 安装

1. 在 GitHub Release 下载 ZIP 并解压；
2. Chrome 打开 `chrome://extensions/`；
3. 开启“开发者模式”；
4. 点击“加载已解压的扩展程序”；
5. 选择解压后的文件夹；
6. 刷新 B 站首页。

项目已经开源：

`github.com/1281300805/bilibili-previous-batch`

目前是 v0.1.0。如果 B 站更新首页结构导致按钮消失，可以在 GitHub Issues 留下 Chrome 版本和截图，我会继续适配。

这是我第一次把自己遇到的小问题做成浏览器扩展。如果你也遇到过“刚才那批去哪了”，欢迎试试，也欢迎提建议。
